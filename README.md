# 微信 BOT (PI_WeChatBot) For PI-Desktop

> **PI_WeChatBot** 是专为 [PI-Desktop](https://github.com/vastsa/PI-Desktop) 智能体桌面客户端打造的微信官方无缝协同桥梁。  
> 基于微信官方底层通信协议，实现手机微信与电脑端编程智能体的双向对话同步、多模态看图识图、AI 产物文件原生直传与全功能远程掌控。

由 **[Xidea 团队](https://www.ifolo.cn)** 精心出品。

[PI-Desktop](https://github.com/vastsa/PI-Desktop) 团队为我们带来了极其惊艳的 Pi 桌面端体验，让本地桌面端 Vibe Coding 的效率与爽感达到了全新的高度。

发给电脑先跑起来。

## 🌟 核心特性全景

### 1. 📱 手机微信随时遥控编程
- 在微信中直接发送自然语言需求，PI-Desktop 自动调动电脑本地开发环境、终端工具与大语言模型执行复杂任务。
- 真正实现“人离开电脑，任务不断线”。出门在外、会议途中均可通过手机指派开发任务并实时查收结论。

### 2. 📸 多模态视觉图文双向互通
- **微信发图直达 AI**：支持在微信中发送手机截屏、现场照片或架构设计草图。插件后台自动完成 AES-128-ECB 解密并持久化存储，无缝注入当前会话供智能体深度分析。
- **本地图片原生回传**：通过内置的 `send_image_to_wechat` 工具，智能体生成的图表、渲染图或截图可直接原图推送至微信。

### 3. 📦 产物文件原生卡片直传（腾讯 CDN 官方通道）
- **告别手机看代码痛苦**：智能体生成的 Markdown 报告、PDF 方案、导出的 Excel 数据或 Zip 代码包，可通过内置 `send_file_to_wechat` 工具一键直传。
- **官方加密通道**：经由微信官方 C2C CDN 加密直传，以原生文件卡片形式送达微信，手机端可一键预览、保存或转发。

### 4. 🔄 智能单轮闭环与防刷屏消抖
- **精准闭环**：微信发起一次提问，AI 生成完整答复后插件自动收敛解除监听；桌面端后续的人类日常输入绝不骚扰微信手机端。
- **工具流防抖（Turn Debounce）**：智能体执行多步文件读写、终端命令时，自动屏蔽中间状态日志，仅在得出最终完整答复时统一推送，拒绝微信刷屏。

### 5. ✂️ 1200 字符智能防截断与代码块修护
- 严格遵循微信物理消息长度上限，长文本自动切片并追加 `[1/N]` 进度标记。
- **语法树代码块保护**：切片算法自动检测跨分片的 Markdown 代码块，在上一片末尾自动补全闭合符号，并在下一片开头自动延续对应语言前缀，确保移动端代码高亮排版始终完美。

### 6. ⚡ 强大本地秒级响应指令系统
- 手机端发送 `/help`、`/sessions`、`/switch`、`/projects`、`/new`、`/reset`、`/status` 等斜杠指令时，由本地调度器**毫秒级直接响应**，不消耗任何大模型 Token。

### 7. 🛡️ 纯净上下文与持久化隔离架构
- **零规则污染**：微信提示词规范由全局环境隐式托管，桌面端会话中仅保留干净的用户指令，绝无多余冗长的系统提示词样板代码。
- **数据跨版本保全**：用户登录凭据、会话路由配置与接收媒体统一存储于宿主标准数据目录（`~/.pi-desktop/plugins/data/...`），插件升级重载不丢失登录态。

### 8. 🖼️ 原生高清矢量扫码
- 内置纯本地 SVG 矢量二维码引擎，零外部网络与 CDN 依赖，深度适配 macOS / Windows 桌面端的深浅色主题。

### 9. 🎙️ 微信语音转任务 (Voice-to-Task · 车载/通勤闭环)
- 支持直接在手机微信按住说话，微信官方高准确率语音转文字结果自动无损提纯，无缝转化为任务指令派发至 AI。
- 真正实现走路、开车、通勤途中的“动动嘴皮子就能遥控敲代码”。

### 10. ⚠️ 高危操作微信远程授权门禁 (Remote Approval)
- 当智能体执行涉及删除文件（`rm -rf`）、远程推送（`git push`）、格式化等高危操作时，自动拦截桌面弹窗，秒级向手机微信发送确认卡片。
- 用户在微信直接回复 `1`（放行）或 `2`（拒绝），60秒倒计时自动防卡死，彻底解决人不在电脑前时的流程挂起。

### 11. 🔔 长任务完成战报与 Token 审计
- 针对执行多步工具或耗时较长（>10s）的深度任务，回复末尾自动附带极客感执行报告（包含执行总秒数、工具执行步数、模型代号与 Token 精准消耗）。

## 🛠️ 手机端可用远程指令列表

在微信聊天对话框中发送以下指令，本地调度引擎将即时处理：

| 指令 | 别名 / 中文触发 | 功能与说明 |
| :--- | :--- | :--- |
| **`/help`** | `帮助`、`菜单` | 显示包含全部指令的完整欢迎与操作帮助菜单 |
| **`/sessions`** | `会话列表`、`会话` | 检索本地 SQLite 数据库，展示最近活跃的 10 个历史会话及其编号 |
| **`/switch <序号>`** | `/use <序号>` | 切换微信指令绑定的工作会话（如 `/switch 2`） |
| **`/projects`** | `项目列表`、`项目` | 列出电脑当前打开的所有工程工作区目录 |
| **`/new [标题]`** | `新建会话` | 在电脑端快速开辟新独立会话，并在标题前缀标注 `[微信Bot]` |
| **`/reset`** | `重置` | 重置当前会话上下文并刷新微信通信状态通道 |
| **`/status`** | `状态` | 查看助手运行状态、已绑定微信用户、当前目标会话与推送模式 |
| **`/about`** | `关于` | 查看产品介绍、出品团队（Xidea）与官方开源仓库信息 |
| **`/mute`** | `静音`、`/bye` | 立即静音当前会话，停止向手机推送后续所有内容 |
| **`/listen`** | `监听`、`/unmute` | 开启 30 分钟持续镜像推送模式（桌面调试观察模式） |
| **`/stop`** | `中止`、`停止` | 若电脑端智能体正在执行繁重任务，立即远程紧急打断并终止运行 |

> 💡 **日常使用提示**：日常编程提问无需输入任何斜杠指令，直接在微信发送问题（如：“帮我把刚才的 API 接口加上参数校验”），电脑 AI 就会自动处理并回复！

## 🧩 智能体扩展工具（Agent Tools）

插件为 PI-Desktop 智能体注入了专属工具能力，AI 在对话中可自主调用：

- **`send_file_to_wechat`**：
  ```json
  {
    "path": "/workspace/docs/architecture-v2.pdf",
    "displayName": "系统架构设计说明书.pdf"
  }
  ```
  将本地生成的文件以加密原生卡片形式直传并推送到微信。
- **`send_image_to_wechat`**：
  ```json
  {
    "path": "/workspace/output/chart.png"
  }
  ```
  将生成的图表或渲染结果直接发送至用户手机微信。

## 🚀 安装与配置

### 方式一：直接安装打包文件（推荐）
1. 在 [GitHub Releases](https://github.com/XideaDev/Pi-WechatBot/releases) 下载最新发布的 `.piplug` 安装包；
2. 打开 PI-Desktop 的 **插件中心**（Plugins）；
3. 将 `.piplug` 文件拖拽至插件窗口即可秒级完成安装。

### 方式二：本地开发模式加载
1. 克隆代码仓库到本地：
   ```bash
   git clone https://github.com/XideaDev/Pi-WechatBot.git
   ```
2. 打开 PI-Desktop，进入 **插件** 页面，点击右上角 **“加载开发插件”**；
3. 选择包含 `manifest.json` 的目录即可生效。

## 📖 快速上手指南

1. **扫码认证**：
   - 打开控制面板（在命令面板输入 `微信 BOT: 打开控制面板` 或点击左侧边栏图标）。
   - 使用手机微信扫描面板中的高清矢量二维码，手机端点击“允许登录”即可完成绑定。
2. **选择目标会话**：
   - 在控制面板可配置“会话路由规则”：
     - **自动跟随最新活跃会话**（推荐）：手机发起的任务自动路由至最新操作的会话。
     - **锁定特定会话**：定向派发到选定的工程项目会话中。
3. **推送策略配置**：
   - **仅单轮闭环响应**（默认）：微信提问一次，AI 回答完毕后自动保持安静，桌面端后续的人类键盘聊天绝不骚扰微信端。
   - **双向实时镜像**：桌面端与微信发起的对话全量实时推送到微信。

## 🔒 隐私与安全性保障

- **直连腾讯官方底层接口**：所有长轮询与消息收发直接与官方服务器通信，无任何第三方中间服务器留存。
- **安全沙箱凭据保存**：身份凭据仅存留在本地受保护的插件持久化目录。
- **远程紧急熔断**：支持发送 `/stop` 远程紧急掐断智能体正在运行的命令与执行流。
