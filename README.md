# 微信 BOT (PI_WeChatBot)

> **PI_WeChatBot** 是专为 [PI-Desktop](https://earendil.com) 智能体桌面客户端打造的微信无缝协同桥梁。  
> 通过微信官方 iLink Bot Web 协议，实现手机微信与桌面端编程智能体的双向对话同步、文件互传与远程会话掌控。

由 **[Xidea 团队](https://www.ifolo.cn)** 精心出品。

---

## 🌟 核心特性

- **📱 手机微信随时派活**：在微信中直接发送自然语言需求，PI-Desktop 自动调动桌面环境、工具与模型执行任务。
- **🔄 智能单轮闭环响应**：微信提问一次，AI 答复完毕后系统自动收敛；桌面端后续的人类键盘聊天绝不骚扰微信手机端。
- **✂️ 1200 字符智能防截断切片**：解决微信单条文本消息物理限制，严格保护代码块跨片自动闭合与语言前缀，长文自动追加 `[1/N]` 序号进度。
- **⚡ 强大远程控制指令**：支持在手机端直接发送 `/sessions`（查看会话）、`/switch <序号>`（远程切会话）、`/projects`（查看项目）、`/status`（查运行态）、`/mute`（静音）、`/stop`（紧急中止任务）、`/about`（关于团队）。
- **🎨 纯净会话流**：桌面端会话中仅展示干净的用户指令，彻底移除冗余样板规则提示词；交互规范由全局环境隐式托管。
- **🖼️ 原生高清矢量扫码**：面板内置纯 SVG 矢量二维码生成器，零外部 CDN 依赖，暗黑/明亮主题自动适配。

---

## 🛠️ 手机端可用远程指令

在微信对话框中发送以下任意指令，即可由本地调度器秒级响应（不消耗模型 Token）：

| 指令 | 别名 / 中文触发 | 作用与功能说明 |
| :--- | :--- | :--- |
| **`/help`** | `帮助`、`菜单` | 显示包含全部指令的完整欢迎与操作菜单 |
| **`/sessions`** | `会话列表`、`会话` | 查看当前最近活跃的 6 个对话会话与数字序号 |
| **`/switch <序号>`** | `/use <序号>` | 手机端直接切换微信指令绑定的会话（如 `/switch 2`） |
| **`/projects`** | `项目列表`、`项目` | 列出电脑上当前打开与已登记的所有工程项目目录 |
| **`/status`** | `状态` | 查看助手当前连接状态、当前会话及推送模式 |
| **`/about`** | `关于` | 查看 PI_WeChatBot 简介、Xidea 开发团队与官网信息 |
| **`/mute`** | `静音`、`/bye` | 立即静音当前会话，停止向手机推送后续所有内容 |
| **`/listen`** | `监听`、`/unmute` | 开启 30 分钟持续镜像推送模式 |
| **`/stop`** | `中止`、`停止` | 若电脑端 AI 正在执行耗时较长任务，立即紧急取消 |

> 💡 **提示**：日常编程无需输入任何斜杠，直接在微信发送问题（如：“帮我检查代码有没有语法错误”），电脑 AI 将自动处理并回复到微信！

## 🚀 安装与使用

### 方式一：直接安装打包文件（推荐）
1. 在 Release 页面下载最新的 `cn.ifolo.pi-wechatbot-1.1.0.piplug`；
2. 打开 PI-Desktop 的 **插件**（Plugins）管理页面；
3. 将 `.piplug` 文件拖拽至插件窗口即可完成安装。

### 方式二：开发插件加载
1. 克隆本项目到本地：
   ```bash
   git clone https://github.com/XideaDev/Pi-WechatBot.git
   ```
2. 打开 PI-Desktop，进入 **插件** 页面，点击右上角 **“加载开发插件”**；
3. 选择包含 `manifest.json` 的目录即可完成加载。

---

## 📖 使用指南

1. **扫码认证**：
   - 安装完成后，在命令面板输入 `微信 BOT: 打开控制面板`（或在插件列表点击面板图标）。
   - 手机微信扫描面板中的二维码，并在手机上点击“允许登录”。
2. **选择目标会话**：
   - 在面板的“会话路由与派发目标”中，可选择“自动跟随当前最新活跃会话”或锁定特定工程会话。
3. **推送策略配置**：
   - **仅单轮闭环响应**（默认推荐）：微信问一条 AI 答一条，答完自动安静，桌面打字不打扰手机。
   - **全局双向镜像**：桌面和微信发起的对话全量实时推送到微信。

---

## 🔒 隐私与安全性

- **直连腾讯官方 iLink Bot 服务**：所有消息与长轮询直接通过官方接口通信，不经过任何第三方中转服务器。
- **本地存储凭据**：登录凭据仅保存在当前设备本地的插件数据目录中。
- **敏感信息守卫**：支持远程 `/stop` 紧急打断与单轮生命周期收敛，杜绝无关内容泄露。
